This is a prioritised planning guide, not a claim that work has been completed.

- Apply to suitable Cloud, DevOps, Platform, Support, DevSecOps and AI Systems roles.
- Practise explaining actual work and trade-offs.
- Tailor the CV to each relevant role.
- Do not delay applications until every project is complete.

1. DevFlow Platform: document verified structure, tests, CI and deployment.
2. Cloud Resume Challenge: verify correct repo/access and document only confirmed AWS functionality.
3. Phoenix Capstone: document architecture and current state without claiming unresolved CI issues are fixed.

5. GitHub profile and portfolio: link to strong, evidence-backed project pages.

## Track 3 — AI engineering (one main build at a time)
1. LangGraph Incident Triage: small MVP with evidence input, specialist analysis, approval and auditable output.
2. Resumable LangGraph Workflow: focus on checkpointing and resume semantics.
3. LiteLLM AI Gateway: local model routing and cost/latency measurement before cloud deployment.
4. Python AI Security Scanner: implement only after checks and expected outputs are defined and testable.

## Track 4 — Cloud and DevSecOps gaps
- Use NextWork as a skill checklist, not a mandatory sequence of 35 separate builds.
- Complete only gaps not already demonstrated.
- Treat observability as an extension of DevFlow or Phoenix unless a separate project adds distinct value.
- Defer standalone multi-cloud implementation until the existing AWS and Azure projects have been inspected.

## Track 5 — Separate, bounded tracks
- Sunshine FDMS: progress in bounded sessions without letting it displace employment.
- Project Aegis: research-first; no live trading or broker credential handling.
- Client/business projects: plan around real deadlines separately.

## December outcomes to target
- Stronger, accurately documented existing projects.
- At least one credible AI engineering demonstration with tests and limitations documented.
- A coherent GitHub profile and portfolio.
- Interview-ready stories based on verified implementation.
