## Safety and duplication rules
- These are local starter structures, not remote GitHub repositories.
- Check GitHub for name conflicts and existing equivalents before creating remote repos.
- Do not make empty repositories look like completed portfolio projects.
- Use a clear `Planned` or `In Progress` label until implementation and verification exist.
- Never commit credentials, private keys, certificates, `.env` files or state containing sensitive values.
- Do not change repository visibility, rename, delete, commit or push without review.
